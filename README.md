My professional background is in telecommunications, device management and systems integration. I bring that experience into native Apple development through debugging, explicit state modeling and recovery-oriented engineering.

## Native Apple applications

### [GlassBox — iOS & watchOS](https://github.com/Charles-drZ/glassbox-showcase)

**Swift · SwiftUI · SwiftData · CloudKit · HealthKit · StoreKit 2 · watchOS**

Active TestFlight and product-hardening work; **not** an App Store release.

[Product overview and real iPhone screenshots](https://github.com/Charles-drZ/glassbox-showcase) · [Habits engineering case study](https://github.com/Charles-drZ/glassbox-showcase/blob/main/docs/habits-week-evidence.md)

### [GlassPort — Native macOS](https://github.com/Charles-drZ/glassport-showcase)

A native developer workspace bringing local shells, SSH connections and terminal sessions into an AppKit application.

**Swift · AppKit · SwiftTerm · PTY · system OpenSSH**

The accepted foundation restores persistent workspace intent while starting fresh terminal processes. Draft features are not presented as shipped.

[Project overview](https://github.com/Charles-drZ/glassport-showcase) · [Architecture note](https://github.com/Charles-drZ/glassport-showcase/blob/main/docs/native-workspace-architecture.md)
